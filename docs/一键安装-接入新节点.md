# 一键安装：接入新节点（deploy/bootstrap.sh）

新边缘盒子（或重装后的盒子）一条命令完成全部初始化：

```
安装并接入 Tailscale → 安装 Docker → 安装 1Panel → 安装 ecp-agent 并接入控制面板
```

## 前置准备（控制面侧，一次性）

1. **注册密钥**：在控制机命令行生成（`server.exe keygen` 的产物）：

   `PowerShell`（在 `server/` 目录）：
   ```powershell
   cd D:\Users\flowe\WorkBuddy\边缘计算-算力节点\server
   .\dist\server.exe keygen my-node   # my-node 是备注标签
   ```
   输出形如 `REGISTRATION_KEY=xxxxxxxx...`，复制它。

2. **Tailscale authkey**（可选）：在 [tailscale admin](https://login.tailscale.com/admin/settings/keys) 生成一次性 auth key
   （不提供则脚本走交互式浏览器登录，节点需你手动确认）。

3. 确认控制面（`ecp-desktop.exe` 或 `server.exe serve`）在运行，且控制机 Tailscale IP 已知
   （例如 `100.68.202.101`）。新节点装好 Tailscale 后通过 tailnet 直连控制面 7443。

## 使用（在目标节点上）

以 root（或 sudo）执行，把脚本放上去（scp 或任意方式）：

```bash
# 1. 把脚本拷到节点（也可直接从 GitHub/你放置的位置下载）
scp bootstrap.sh user@新节点:/tmp/

# 2. 执行一键安装（示例）
sudo bash /tmp/bootstrap.sh \
  --server 100.68.202.101:7443 \
  --key <上一步的 REGISTRATION_KEY> \
  --tailscale-authkey <tskey-auth-xxx> \
  --agent-file ./ecp-agent-linux-arm64 \
  --relay-url wss://edge.api.immml.top/agent \
  --relay-token <节点独立 token> \
  --feishu-webhook https://open.feishu.cn/open-apis/bot/v2/hook/xxxx
```

说明：
- `--agent-file` 手动传二进制（最稳）；或 `--agent-url https://<控制面>:8443/api/v1/agent/binaries/ecp-agent-linux-<arm64|amd64>`（控制面 OTA 下载，免鉴权）
- `--relay-url/--relay-token`：可选，配紧急通道（每节点用独立派生 token）
- `--feishu-webhook`：可选，节点本地告警推飞书群

## 参数表

| 参数 | 必填 | 说明 |
|---|---|---|
| `--server <ip:port>` | ✅ | 控制面 gRPC 地址（Tailscale IP:7443） |
| `--key <key>` | ✅ | 控制面 `keygen` 生成的注册密钥 |
| `--agent-file <path>` | * | 本地 Agent 二进制（与 --agent-url 二选一） |
| `--agent-url <url>` | * | Agent 二进制下载地址 |
| `--agent-sha256 <hex>` | 可选 | 下载后 SHA256 校验 |
| `--ca-url <url>` | 可选 | 控制面 CA 证书地址（默认自动探测 `server` 的 IP:8443/api/v1/ca.crt） |
| `--https-port <port>` | 可选 | 控制面 HTTPS 端口（默认 8443） |
| `--tailscale-authkey <key>` | 可选 | Tailscale 接入 authkey（缺则交互登录） |
| `--no-1panel` | 可选 | 跳过 1Panel 安装 |
| `--relay-url / --relay-token` | 可选 | 紧急通道（Worker 地址 + 节点 token） |
| `--feishu-webhook` | 可选 | 节点告警推送 Webhook |
| `--prefix <dir>` | 可选 | Agent 安装目录（默认 /opt/ecp-agent） |
| `--cfg-dir <dir>` | 可选 | 配置目录（默认 /etc/ecp） |
| `--svc <name>` | 可选 | systemd 服务名（默认 ecp-agent） |
| `--force` | 可选 | 已装 Agent 时强制重装 |
| `--dry-run` | 可选 | 只检测与打印计划，不安装 |

## 脚本做了什么

1. **Tailscale**：检测已装/运行 → 未装走官方脚本 → `tailscale up` 接入（authkey 或交互）→ 输出节点 100.x 地址
2. **Docker**：检测已装跳过 → 未装官方源安装（失败给出阿里云镜像与官方文档指引）
3. **1Panel**：检测已装跳过（`--no-1panel` 可关）→ 未装官方 quick_start 安装
4. **ecp-agent**：
   - 创建专用运行用户 `ecp-agent`（非 root，符合最小权限）
   - 安装二进制 → 生成 `agent.yaml`（控制面地址/注册密钥/可选 relay/告警）→ 写入 `registration.key`
   - **自动拉取控制面 CA**：优先 `--ca-url`，否则探测 `<server-IP>:8443/api/v1/ca.crt`
     （免鉴权端点，PEM 校验；已存在则跳过）——没有 CA 节点 TLS 握手会失败
   - 写 systemd 单元 `ecp-agent.service`（`--svc` 可改名）并 `enable --now`
   - 日志确认接入状态

## 装完做什么

```
控制面板 → 节点列表 → 新节点应显示 online
节点详情 → 下发指令（如 docker ps / systemctl status）验证控制链路
组网页 → 配置 FRP/紧急通道（可选）
1Panel → 1pctl user-info 查看安全入口（脚本权限严格，不读取/绕过其凭据）
```

## 幂等与重装

- 所有组件"已装则跳过"；再次执行安全
- Agent 已装且服务运行 → 提示跳过（`--force` 重装）
- 全新盒子/重装系统：直接再跑一次脚本即可重新接入，无需人工审批（符合"上线即控"）

## 卸载

```bash
sudo systemctl disable --now ecp-agent
sudo rm -rf /opt/ecp-agent /etc/ecp /etc/systemd/system/ecp-agent.service
sudo userdel ecp-agent
```

## 国内网络提示

- Tailscale/Docker 官方源国内可能受限，失败时脚本打印替代源指引（pkgs.tailscale.com 手动 deb、Docker 阿里云镜像 `--mirror Aliyun`）
- 1Panel 官方源（fit2cloud）国内可用
- Agent 二进制建议直接从开发机 scp（`--agent-file`），避免公网下载依赖
