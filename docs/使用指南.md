# 边缘节点控制平台 — 使用指南

> 一句话形态：**控制面一个 exe（Windows 控制机）、Agent 一个静态二进制（每台边缘节点）、中间靠 Tailscale 组网**。浏览器打开控制台即可管理所有节点。

---

## 一、三端关系

```
┌─────────────────┐      Tailscale (WireGuard P2P)      ┌──────────────────┐
│  控制面 server.exe  │◄──────── 注册/心跳/遥测/指令 ────────►│  Agent（每节点）   │
│  Windows 控制机     │  HTTPS 控制台 :8443  / gRPC :7443 │  Orange Pi 等     │
└─────────────────┘                                     └──────────────────┘
        ▲  浏览器打开 https://127.0.0.1:8443
        └─ 管理员操作：看节点/下发指令/看遥测/审计
```

## 三、接入一台边缘节点（Linux）

### 1. 准备文件（从控制机取）
- `agent/dist/ecp-agent-linux-arm64`（或 amd64 版）
- `server/runtime/data/certs/ca.crt`（控制面 CA 公钥）

### 2. 拷贝并安装

`Linux (边缘节点)`
```bash
sudo mkdir -p /opt/ecp-agent /etc/ecp
sudo cp ecp-agent-linux-arm64 /opt/ecp-agent/ecp-agent
sudo chmod +x /opt/ecp-agent/ecp-agent
sudo cp ca.crt /etc/ecp/ca.crt
```

### 3. 写配置 `/etc/ecp/agent.yaml`

```yaml
agent:
  node_id: ""            # 留空，首次注册时自动分配
  data_dir: /opt/ecp-agent
  config_dir: /etc/ecp
  log_level: info
registration:
  key: "把上面 keygen 输出的 REGISTRATION_KEY 填这里"
control_plane:
  endpoints:
    - "100.68.202.101:7443"   # 控制面的 Tailscale IP:gRPC 端口
  ca_cert: /etc/ecp/ca.crt
  client_cert: /etc/ecp/client.crt   # 注册成功后自动写入
  client_key: /etc/ecp/client.key
telemetry:
  interval: 30s
cache:
  path: /opt/ecp-agent/cache.db
  retention: 168h
alert:
  rules_file: /etc/ecp/alert-rules.yaml
```

### 4. 启动（推荐 systemd 自启）

`Linux (边缘节点)`
```bash
sudo /opt/ecp-agent/ecp-agent run -c /etc/ecp/agent.yaml
```
验证：日志出现 `注册成功 node_id=n-xxxx` / `已连接到控制面` 即成功。此后重启自动免注册重连；配 systemd 单元（`Restart=always`）实现开机自启。

## 四、控制台日常操作

| 页面 | 能做什么 |
|---|---|
| **节点列表** | 全部节点在线/离线、基本信息 |
| **节点详情** | 系统信息、CPU/内存/磁盘/温度实时值 + **历史趋势图**（15s 自动刷新） |
| **下发指令** | 对在线节点执行 SHELL 命令（如 `docker ps`、`systemctl status`），立即回显结果 |
| **审计日志** | 谁、何时、对哪个节点、做了什么（全操作留痕） |
| **告警** | 节点本地规则（CPU/内存/磁盘/温度阈值 + 离线检测），命中推飞书机器人 |

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 忘记 admin 密码 | 删 `server\runtime\data\ecp.db`（保留 certs 目录）后重启 `serve`，新密码打印在日志 |
| 控制台打不开 | 确认 `server.exe serve` 在跑；`netstat -ano | findstr 8443` 看监听 |
| 节点掉线 | 先看节点本身网络（WiFi/Tailscale）；Agent 会自动重连 |
| 新节点注册被拒 | 确认注册 Key 正确、未吊销；`server.exe keygen` 重新生成一份 |
