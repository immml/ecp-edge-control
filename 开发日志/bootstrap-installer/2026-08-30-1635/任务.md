## 关键决策
1. 一键安装按"先组网再装件"：Tailscale 先行，之后 agent 可经 tailnet 直连控制面
2. agent 专用系统用户 ecp-agent（非 root 运行，符合最小权限红线）
3. 二进制来源：--agent-file（scp 最稳）优先，--agent-url 支持控制面 OTA（免鉴权）
4. relay token 不入 systemd 单元明文：EnvironmentFile <cfg>/relay.env 0600
5. 告警推送节流放控制面侧（agent 侧 cooldown 只管本地，控制面聚合推送需独立节流）

## 踩坑（真机验证抓出）
1. registration.key 0600 root → agent 专用用户读不了（Permission denied 伪装成
   client.key 错误）：改为归属运行用户
2. **配置目录必须归运行用户可写**：agent 首启要生成 client.key/client.crt，
   目录是 root-755 就写不进去 → chown -R runuser 配置目录（0700）
3. relay.env 硬编码 /etc/ecp 不跟随 --cfg-dir：已修（$CFG_DIR/relay.env）
4. 杀 desktop 进程：taskkill //IM 在 Git Bash 下参数转换易失效 → PowerShell
   Get-Process|Stop-Process -Force 稳
5. rm desktop.log 被占用（旧进程还在）→ 先杀进程再删
