## 关键决策
1. **iw 优先、nmcli 降级**：iw 信息全（BSSID/freq/真实 dBm/安全），真机已 apt 装 iw；
   无 iw 时「sudo nmcli rescan + list」出精简报告（RSSI 由百分比折算）
2. **评分模型**：拥塞度 congestion=count×20(上限100)，强度=(rssi+90)/40×100，
   综合分=强度×0.6−拥塞×0.4（-40..100，越高越好）；推荐=白名单内信号更强(>阈值且+8dB)
3. **自动切换默认关闭** + 白名单硬红线（防钓鱼/误切）+ 切换后 ping 网关验证失败回退
4. **密码不下发控制面**：前端白名单密码留空 → agent merge 保留旧密码（不回显）
5. **xray 跳板故障根因**：新版 Xray release 无 geoip.dat 资产，routing 引用 geoip:private
   启动即崩；改为内置 CIDR 私有网段规则（更符合项目零外部依赖）
6. **Tailscale IP SSH 认证超时**（100.108.234.5），但 LAN IP 正常；SSH 走 192.168.1.5
