## 踩坑（真机抓出，文档已收录）
1. `-c file keygen` ≠ keygen：args[1] 必须为 "keygen"，配置走 ECP_CONFIG env；
   写错会被当 serve 启动（还占 7443，需 pkill -x ecp-server 清理）
2. **重置库后 keygen 的 key 作废**（registration_keys 表被清）——必须先重置再 keygen
3. 节点 TLS 握手失败=缺云端 ca.crt（ca.crt 不是自动下发的）
4. **key 文件带 \n → sha256 不匹配注册被拒**（echo > file 常见坑）→ 代码 TrimSpace +
   部署 printf 双保险
5. paramiko exec 阻塞读超时 → 硬 shell 循环读收尾
6. pkill -f 会误杀 ssh 会话自身的命令串 → 用 pkill -x 精确进程名
