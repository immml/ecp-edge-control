# 任务：桌面 APP（控制面板应用化）

日期：2026-08-30 14:20-14:50
提交：55119ab（已推送）

## 目标
用户需求："我要的是一个单/多文件 APP，打开就可以使用"——不是浏览器访问 127.0.0.1。

## 工具链决策
- 本机：无 Rust（Tauri 需 1-2GB 工具链）、有 Go 1.27 + WebView2 151（Win10/11 自带）
- 选定 **Go + WebView2**：零新依赖、复用全部现有 server 逻辑、单 exe 双击即用
- `github.com/webview/webview_go` 需 cgo/MINGW → 弃用
- `github.com/jchv/go-webview2`（Wails 官方团队，纯 Go winloader 加载内嵌
  WebView2Loader.dll）→ 选用，编译验证通过

## 变更文件
- `server/cmd/desktop/main.go`（新增）：桌面 APP 入口
  - 复用 store/ca/grpcserver/command/api 全套
  - HTTP 回环随机端口（127.0.0.1:0）——WebView2 无自签证书问题
  - gRPC 0.0.0.0:7443 不变（节点回连）
  - webview2.NewWithOptions + Navigate(http://127.0.0.1:port)
  - 数据目录便携：exe 同级 /data（desktop.log/ecp.db/certs）
  - 窗口关闭 → srv.Shutdown 优雅退出
- `server/go.mod / go.sum`：+ jchv/go-webview2 + winloader
- `docs/使用指南.md`：新增"四·五、紧急通道使用方法"
- `server/dist/ecp-desktop.exe`（构建产物，34MB）

## 关键决策
1. HTTP 而非 HTTPS：WebView2 拦自签证书整页；回环监听无外部访问面
2. 数据目录随 exe：便携迁移（复制文件夹即换机器）
3. 不重构 api.New/server 逻辑：desktop 独立入口，双形态（server serve / desktop）共存

## 踩坑
1. webview_go 需 cgo → 换 jchv/go-webview2（纯 Go）
2. **NoRoute SPA 回退漏复制 → 根路径 404**：desktop 用 api.New 后必须补
   engine.NoRoute + web.FS()（与 server/main.go 一致）
3. gui 测试会话限制：PowerShell/Bash 工具会话无法稳定跑 GUI 窗口程序
   （Start-Process/explorer 均不可靠）；真实桌面双击验证窗口正常+SPA 200

## 验证
- 窗口标题 `ECP 边缘节点控制台 vdev`（真实双击）
- SPA 根路径 HTTP 200（<!DOCTYPE html>）、login API 401（服务正常）
- gRPC 7443 + HTTP 127.0.0.1 随机端口双监听
- Pi agent 自动重连入口就绪

## 遗留
- 多节点 token 独立设计
- desktop 图标/版本号注入（-ldflags -X）/正式发布打包（NSIS/Inno）
- 退出时本机浏览器兜底提示（可选）
