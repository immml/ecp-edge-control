## 关键决策

**1. 能力探测的核心原则：不看命令在不在，只看操作能不能成。**

这是本次最重要的决策，直接来自真机教训。Orange Pi 上 `docker` 二进制存在（29.6.1）但用户不在 docker 组，如果用 `exec.LookPath("docker")` 判断，会误报"支持容器管理"——用户点下去才失败，这是最糟糕的体验。

所以：
- Docker 能力 = 真去 `net.DialTimeout("unix", "/var/run/docker.sock", 2s)`
- Tailscale 纳管 = 真去执行 `tailscale status --json` 并等待其成功退出
- 所有探测带超时，Agent 启动不因单条命令卡住

同时写了 `TestProbeDockerSocketContract` 把这条契约锁进测试，防止后人改回 LookPath。

**2. 审计日志 append-only 落到代码约束上。**

`store` 包只暴露 `AppendAudit`，刻意不提供 Update / Delete。这不是"暂时没写"，是"不提供"。审计不可篡改是合规底线，靠文档约束不住，要靠 API 面约束。

**3. 注册 Key 只存哈希。** 明文仅在签发那一刻展示一次，库里无法找回。

**4. DiscoveredPeer 只记录不自动纳管。** 发现与纳管是两件事，纳管必须由人显式发起并持有注册 Key。这是合规红线在代码层的体现。

**5. 配置零依赖可跑。** 每个字段都有默认值，空配置文件也能启动。控制面是"按需启动的个人管理终端"，不该让用户先读文档才知道怎么起。

**6. 容器隔离标签 `ecp.managed` 进配置。** 为"A6 不碰业务容器"提供实现基础——Agent 将来只对带这个标签的容器执行写操作。
