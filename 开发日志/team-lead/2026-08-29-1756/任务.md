## 关键决策

**1. 视觉基准选 Cloudflare Dashboard 而非深色后台。**
浅色侧边栏 `#fbfbfd`、卡片白底 + 1px 边框 `#e6e8eb`、6px 圆角、几乎无阴影。理由：这是**个人开发者的管理终端**，不是 NOC 大屏，浅色更耐看、信息密度适中，长时间盯着不累。主题色 `#6b37c9` 贯穿主按钮、进度条、导航激活态、图标高亮。

**2. 容器列表在 UI 层就落实隔离红线。**
mock 里的 `wxedge` 等业务容器被标为「节点既有业务」，操作按钮直接 `disabled`。不是等后端拦截，而是**从界面上就不给误操作的入口**——后端 label 校验是第二道防线，UI 是第一道。

**3. mock 数据全部用真机实测值，不编造。**
3.8 GiB 内存、232G 磁盘、负载 8.11、温度 56.1°C、Tailscale IP 100.108.234.5。这样真机联调时数字不会跳变，也不会让人对量级产生错误预期。

**4. 终端页用回显模式占位，但保持真实交互观感。**
光标闪烁、退格、换行都做了，后端 WebSocket 就绪后只需替换数据源，组件不动。

## 踩坑（四条，后两条很隐蔽）

**坑 1 · Vite 8 的 rolldown 把 .vue 误判为 JSX。**
构建报 `[PARSE_ERROR] Unexpected JSX expression`，提示 JSX 语法未启用。根因是 Vite 8 换用 rolldown 打包器，与当时的 plugin-vue 组合异常。
解法：降级 `vite@6.4.3` + `@vitejs/plugin-vue@5.2.4`。降级时 npm 报 ERESOLVE 冲突，需加 `--legacy-peer-deps`。

**坑 2 · TypeScript 7 不再导出 `./lib/tsc`，vue-tsc 启动即崩。**
报 `ERR_PACKAGE_PATH_NOT_EXPORTED`。TS 7 是 Go 重写版，内部路径变了。
解法：降级 `typescript@5.9.3`。**教训：，`latest` 不等于可用，尤其跨大版本时。**

**坑 3 · xterm 旧包名全部废弃。**
`xterm` / `xterm-addon-fit` / `xterm-addon-web-links` 均已 deprecated，新包名为 `@xterm/xterm`、`@xterm/addon-fit`、`@xterm/addon-web-links`。npm 安装时会警告，别忽略。

**坑 4 · 工具调用串行化异常导致文件静默未创建（最隐蔽）。**
在同一次响应里同时发起 Bash 与 Write 时，Write 的内容被拼进了 Bash 命令末尾，导致：Bash 报 `unexpected EOF`，同时 **Write 的文件根本没有创建**。
后果：`vite.config.ts` 缺失，但排查时看到的是"plugin-vue 未安装"这类误导性报错，绕了一圈才发现文件不存在。
**后续约束：不在同一轮里混合 Bash 与 Write；写文件后用 `ls` 或构建验证文件确实存在。**
